# Reusable AI systems, creative tools and simulation research

I build independent components and practical applications that help test them. The common thread is making inputs, execution and results visible enough for people and agents to inspect and improve.

**[Explore the portfolio](https://mrscripty.github.io/MrScripty/)**

## Local AI and agent tools

- [Pumas Library](https://github.com/MrScripty/Pumas-Library): acquire, store and share local models across applications
- [Pantograph](https://github.com/MrScripty/Pantograph): build node-based AI workflows and inspect retained execution data
- [Chrema](https://github.com/MrScripty/Chrema): compose agents from reusable, observable components
- [Passeur](https://github.com/MrScripty/Passeur): delegate coding work across providers with durable tasks and repository coordination
- [Coding Standards](https://github.com/MrScripty/Coding-Standards): graph-memory and agent-interface research with typed MCP tools
- [Whip Docs](https://github.com/MrScripty/whip-docs): a developing visual workspace for understanding code and guiding coding agents
- [Eidetic](https://github.com/MrScripty/Eidetic): shape context over time through a clip-based knowledge graph
- [Pumas Playground](https://github.com/MrScripty/Pumas-Playground): inspect a running Pumas gateway and test model operations

## Creative software

[Pentimento](https://github.com/MrScripty/Pentimento) explores hybrid rendering interfaces; [Crispen](https://github.com/MrScripty/Crispen) provides reusable color tools; [Korino-Reaves](https://github.com/MrScripty/Korino-Reaves) inspects Unreal assets.

[Tuldok](https://github.com/MrScripty/Tuldok) supports dataset and training workflows. [Book-Be-Gone](https://github.com/MrScripty/Book-Be-Gone) turns captured book pages into editable text. [Commonlight](https://github.com/MrScripty/Commonlight) explores consent-based portrait presentation, and [Lanternwake](https://github.com/MrScripty/Lanternwake) is a Godot/C# visual novel with separately developing local-AI conversations.

## Physics and simulation

- [Rheon](https://github.com/MrScripty/Rheon): a general 3D fluid-physics solver in development, generating simulation data toward faster AI solvers and inspectable comparisons
- [Rheon Surrogate Lab](https://github.com/MrScripty/rheon-surrogate-lab): learned-pressure experiments with retained data, numerical comparisons and bounded timing evidence
- [Kenoma](https://github.com/MrScripty/Kenoma): anatomically detailed muscle/skeleton and contracting-soft-body simulation in development, with independent schematic posing tools

Each repository distinguishes its current implementation, measured results and remaining research. Connections between projects do not imply completed integrations.

## Books

- [Training Your Own Models on One 24 GB GPU](https://bc-ai-ecosystem.github.io/training-your-own-models/): a project-first handbook, vibe authored by Dr.Puma and transferred to BC+AI
- [Practical Data Analysis for Engineering Decisions](https://mrscripty.github.io/practical-data-analysis/): measurement, comparisons, uncertainty and reproducible analysis
- [Dataset Production](https://mrscripty.github.io/dataset-production/book/): build, audit and release datasets with explicit evidence and consumer contracts
- [Cooking the Cat](https://mrscripty.github.io/Cooking-The-Cat/): my development approach, assembled by an agent analyzing engineering conversations

I also write about contribution, belonging, shared power, knowledge graphs and agentic memory. The [Pantograph research collection](https://github.com/MrScripty/Pantograph/blob/b09380618224277e21fc5be2a2fe7ccc21e9d7dd/docs/research/README.md) documents inference, execution, provenance and scheduling research.

[Studio Whip](https://github.com/MrScripty/Studio-Whip), the original creative-production application, remains a longer-term goal supported by this foundational work.
