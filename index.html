Pumas Library

for local models.

  • Resumable downloads, import, and integrity repair

Pantograph

Make the workflow
visible.

A local-first, Rust-native platform for node-based AI workflows. The optional Svelte/Tauri workbench sits over native workflow, inference, scheduling, and diagnostic modules.

  • Node contracts and graph-based composition
  • Resource-aware runtime scheduling
  • Run artifacts, diagnostics, and provenance
RustSvelte / TauriGraph tooling
Explore the source Architecture & status
Technical scope & verification

Moving toward durable, scheduler-owned task execution. Implementation status is tracked in the repository; there is currently no single green repository-wide compliance command. The captures show native deterministic execution and browser editor rendering as separate surfaces. Desktop submission and model inference are outside this demonstration.

04NUMERICAL RESEARCH

Rheon

Fluid guidance for image-making.

A modular Rust experiment in low-resolution fluid guidance, with a native comparison UI and headless CLI. The fixed-box core supports pressure-solver comparisons and represented liquid-volume transport.

Research scope

An initial comparison laboratory. Free-surface pressure and other physical coupling remain open; this is not a qualified production fluid simulator.

Source Comparison contracts
053D TOOLING / RESEARCH

Kenoma

A simple, direct way to pose.

An embeddable static WebGL/WASM posing editor with multiple characters, scene gizmos, two-bone IK, and undo/redo. Headless graph, mesh, persistence, and rig modules are separate from its biomechanics research.

Research scope

The implemented posing tool is schematic. It makes no anatomical-accuracy or physical-simulation claim; the mechanics book is educational research.
